Pre-RERA Project Watch

Projects where a RERA application or registration process is visible in public HRERA records, but the final RERA registration certificate is not yet confirmed as uploaded.

What this page tracks: applications under examination, hearing/adjournment, deficiency compliance, approved-but-certificate-not-uploaded records and other identifiable pre-registration stages. This is intentionally separate from the RERA Project Watch, which focuses on registered/approved records.
3500–4500 verification: This is the working HRERA detail-record reconciliation scope. A detail-record ID is not the RERA registration number. In the latest verification, Faridabad and Palwal records found in this range were checked for current status; records already showing APPROVED AND CERTIFICATE UPLOADED are deliberately excluded from this pending page. Only records without confirmed final registration/certificate are shown.

Disclaimer / Important Notice
This page is an informational tracker compiled from publicly available Haryana RERA (HRERA) records. “Pre-RERA” means that the public record shows an application/registration proceeding but final registration/certificate is not confirmed on the record used for this tracker. It does not mean that a project is legally exempt from RERA or approved for sale.

HRERA records, hearings, deficiency notices, orders and certificates can change. A project can move from this page to the registered RERA watch after approval. Always verify the latest official HRERA record/order/certificate before booking, purchase, sale or investment.
